# YOSYA artworks

Only YOSYA's original artwork belongs here. These files are ignored by Git and are never served from `public/`.

When the originals are ready, use stable names:

- `artwork-01.webp`
- `artwork-02.webp`
- `artwork-03.webp`

Keep full-resolution source files outside the deployed project. The website should receive optimized AVIF/WebP versions and separately prepared fragments.
