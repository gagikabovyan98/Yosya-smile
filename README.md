# YOSYA — закрытый интерактивный опыт

Рабочая локальная версия персонального cinematic-сайта.

## Запуск

Нужен Node.js 22 или новее.

```bash
npm install
npm run dev
```

Открыть: `http://localhost:3000`.

Тестовый вход:

- логин: `YOSYA`
- пароль: `yosya`

Перед публикацией данные нужно заменить. Новый Argon2-хеш создаётся командой:

```bash
npm run hash-password -- "новый пароль"
```

В `.env.local` используются `YOSYA_PASSWORD_HASH`, `YOSYA_LOGIN` и длинный случайный `SESSION_SECRET`. Знаки `$` в Argon2-хеше должны быть записаны как `\$`.

## Что готово

- одноразовый вход: токен расходуется при первом открытии опыта; обновление, новая вкладка и повторное открытие возвращают на логин;
- ограничение частоты неудачных попыток;
- 17 самостоятельных сцен: вход, распознавание, четыре разные проверки, две разные фрагментации, книжный разворот, готические рамы, zoom-out, фотокомпозиция из четырёх оригиналов, три точки, сбой, путешествие, большой финальный зал, психопаспорт, загрузка мотылька и библиотека с двумя интерактивными книгами;
- семь физических вариантов рам в `AristocraticFrame`;
- локальные иллюстрированные свечи, включая отдельную потухшую версию с дымом;
- локальная музыка и звуковые акценты; источники и лицензии записаны в `public/audio/LICENSES.md`;
- desktop/mobile-адаптация и режим `prefers-reduced-motion`;
- потоковое воспроизведение длинной музыки без декодирования всего трека в оперативную память.

## Что заменить позже

Все видимые тексты заполнены по-русски, технических заглушек в experience нет. При необходимости перед публикацией остаётся заменить только тестовые данные входа.
